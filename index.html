Getting started

Up and running in three steps.

LocalBridge is intended for devices that can communicate over the same local network. Exact permissions and setup prompts depend on your device and OS version.

Install both apps

Download the Android APK for your phone and the DMG for your Mac from the release section below.

Connect on your network

Open LocalBridge on both devices and follow the app’s discovery and connection flow. Allow the required permissions when prompted.

Share what you need

Use the available clipboard and file-sharing controls to move content between your devices.

Network & security note: LocalBridge uses local-network communication. Being on a local network does not by itself guarantee encryption or authentication. Use trusted networks and review the repository documentation before handling sensitive information.

Good to know

Frequently asked questions.

Is LocalBridge free?

The source repository and v6.0 release assets are publicly available on GitHub. Check the repository for licensing details; the project README currently indicates that a license has not yet been selected.

Do both devices need the same network?

LocalBridge is designed around local-network communication, so the devices generally need network connectivity that allows them to discover and reach one another.

Is the Android APK a production release?

The currently published APK is identified as a debug build. It is best treated as a test build rather than a verified, production-signed release.

Where can I see the source code?

The complete public repository includes the Android and macOS project source, documentation, and protocol test fixtures.
