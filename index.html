01 / THE IDEA

Your devices work better
as one.

LocalBridge is a companion for the small handoffs that happen all day: a line of text, a file, a thought you want on the other screen. It brings those moments closer without adding another complicated workflow.

Designed for everyday use.

05 / A FEW DETAILS

Good to know.

Do both devices need the same network?+

LocalBridge is designed around local-network communication. The network needs to allow the devices to discover and reach one another.

Is the Android APK production-ready?+

The currently published v6.0 APK is identified as a debug build, so treat it as a test build rather than a verified production release.

Is LocalBridge open source?+

The project repository is public on GitHub. Check the repository for current licensing details before redistributing or adapting the code.

What about privacy and security?+

Local-network communication alone does not guarantee encryption or authentication. Use trusted networks and review the source and documentation before handling sensitive information.
